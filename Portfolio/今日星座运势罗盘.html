课堂知识点：这段代码到底在练什么？

input 输入

通过 input 让用户输入星座名称，并保存到变量 star。

random.randint

通过 random.randint(1, 3) 生成 1 到 3 的随机运势编号。

if / elif 多分支

根据不同星座进入不同分支，12 星座对应 12 条判断路径。

嵌套 if

每个星座内部继续判断 num，输出 3 种不同运势。

else 兜底

当输入不是 12 星座之一时，使用 else 提示输入有误。

本页面没有重新 input，也没有重新 random；展示结果来自原代码运行后的 star 和 num。
